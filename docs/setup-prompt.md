# Подключение по инструкции

Скопируйте блок ниже в AI-приложение, которому доступны команды или настройки MCP. Оно сможет выполнить доступную часть настройки. В обычном чате без этих возможностей получите короткие ручные шаги. Вход и выбор доступа происходят в браузере, под вашим аккаунтом.

```text
Подключи Trippi к этому AI-приложению: https://trippitroppa.app/mcp
Транспорт: Streamable HTTP. Авторизация: OAuth + PKCE, автоматическая регистрация по метаданным сервера.

1. Сначала определи свои возможности: есть ли инструменты Trippi, настройки MCP или выполнение команд. Не утверждай, что подключено, пока не прочитаешь доступные поездки через MCP.
2. Если Trippi уже работает, используй существующее подключение. Если настроен, но требует входа — запусти повторный вход. Не создавай дубликат. Не заменяй существующий сервер с тем же именем и другим адресом без моего решения. Не выводи конфиги или секреты целиком.
3. Если доступны команды Codex CLI: проверь существующее подключение командой codex mcp get trippi --json. Только если его нет, выполни codex mcp add trippi --url https://trippitroppa.app/mcp. Если вход не завершился при добавлении, выполни codex mcp login trippi. Сохрани остальные настройки.
4. Если это Claude Code: проверь существующий сервер командой claude mcp get trippi. Только если его нет, выполни claude mcp add --transport http trippi https://trippitroppa.app/mcp. Для входа открой /mcp и предложи мне подтвердить авторизацию Trippi.
5. Для другого клиента используй его штатный способ настройки удалённого MCP. Если настройки и команды недоступны, честно скажи об этом и дай короткие ручные шаги: https://github.com/SherVonemes/trippi-mcp/blob/main/docs/clients.md . Не устанавливай лишние программы и не запускай скрипты из интернета.
6. На этапе OAuth дай мне самому войти и выбрать поездки/разрешения. Не проси пароль, код входа, cookies или токены в чат. Не подтверждай доступ за меня. Если нужно перезапустить приложение/разговор, предупреди и после этого продолжи проверку.
7. После подключения прочитай список доступных поездок и текущие возможности/права. Если я назвал поездку, найди её; при нескольких совпадениях уточни. Если поездка не названа, предложи доступные. Прочитай актуальный контекст и План выбранной поездки. Пока ничего не меняй.

Сообщи точный результат: настройки добавлены, нужен вход или чтение поездки действительно работает. После этого я смогу давать обычные поручения вроде «Открой мою поездку в Питер и помоги с планом».
```

## Если уже подключено

Достаточно попросить: **«Открой мою поездку в Питер и помоги с планом»**. Помощник должен сначала прочитать доступные поездки и актуальный контекст, а после порученного изменения — перечитать результат. Доступ зависит от выбранных поездок, разрешений и вашей роли.

## Что автоматизируется

Добавление адреса сервера и запуск входа — при доступе приложения к соответствующим настройкам. Сайт или инструкция не устанавливают плагин в произвольный чат. Авторизация, выбор поездок и разрешений остаются вашими действиями.

Команды Codex проверены по установленному CLI; [документация MCP](https://learn.chatgpt.com/docs/extend/mcp?surface=cli). Команды Claude Code сверены с [официальной документацией](https://code.claude.com/docs/en/mcp). Возможность менять конфигурацию из текущего разговора зависит от приложения и его разрешений.
